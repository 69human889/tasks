
# 📁 Interview Tasks Collection

## Overview

This repository contains a collection of **projects and coding tasks** assigned to me during **data engineering and development interviews**.

Each task or project is organized in its own directory, and every directory contains a **dedicated README** explaining the project, its purpose, setup instructions, and usage.

---

## Usage

To explore any task:

1. Navigate into the corresponding directory.
2. Open the `README.md` file inside that directory for **full project details, setup instructions, and usage**.

---

## Notes

This repository is structured to **keep each project self-contained**. You can review each project independently, as all required code, configuration, and instructions are provided within its folder.
